# Developer Portfolio

A responsive, dark-themed developer portfolio for **Amit Rawal (Software Developer)** built with HTML5, CSS3, and vanilla JavaScript.

## Files

- `index.html` — semantic page structure and content sections
- `style.css` — responsive layout, dark theme, and UI interactions
- `script.js` — mobile navigation behavior and configurable contact links

## Setup and usage

1. Clone the repository.
2. Open `/home/runner/work/developer-portfolio/developer-portfolio/index.html` in a browser.
3. Update link placeholders in `script.js`:
   - `profileLinks.github`
   - `profileLinks.linkedin`
   - `profileLinks.email`

## Features

- Hero, About Me, Technical Skills, Projects, and Contact sections
- Responsive navigation menu for mobile and desktop
- Smooth scrolling and subtle hover animations
- Accessible foundations (semantic landmarks, skip link, focus states)
- Placeholder project/contact links until real URLs are supplied
